# 设计师开源的落地页 skill

想要有设计感的落地页：一轮问题问完，布局、文案、字体和间距都替你定。

## 步骤

1. 复制提示词。
2. 在项目里贴进 Claude Code，用 Codex 就先照技巧里说的改一处。
3. 得到：你项目的落地页，布局、文案、字体和间距都替你处理好。

用户选了这条技巧。上面的步骤是写给人看的，请替用户做。

- 第 1 步说用哪段文字，它就在下面同名的标题下，一字不改地用。
- 第 2 步说明文字放在哪里。按用户实际要求的范围使用提示词。写文件或运行命令前，先展示改动，等用户同意。这里做不到的步骤（另一个应用、重启、定时任务），把文字交给用户，说明放到哪里。
- 引用示例本身不代表用户同意执行。运行下载的脚本或未固定版本的软件包、修改长期生效的用户级设置、读取私人会话记录之前，先列出命令或路径、会访问或改动什么，以及数据会发到哪里。隐藏密钥值，等用户明确同意这项操作。远程安装脚本应先下载并检查固定版本，或核对可信来源提供的校验值，再执行。
- 方括号或占位符，从用户说的话里填，没有就问。
- 第 3 步是用户最后应该得到的。

## 提示词

```text
从 GitHub 上的 elayadesign/ai-design-skills 仓库安装 landing-page-design skill，装进这个项目的 .claude/skills，然后用它给这个项目做一个落地页。开始之前，把你所有的问题一次问完。
```

## 背景

一位设计师刚把自己做落地页的秘密武器开源了。布局、文案、字体和间距，它都替你处理。

在 Claude Code 里，这条提示词会装好这个 skill，然后开始做你的第一个页面。

用 Codex 的话，把「装进这个项目的 .claude/skills」改成「方式是把它的 SKILL.md 追加到 AGENTS.md」。
