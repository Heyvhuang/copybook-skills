# 120 个可点选的动效样例库

动效靠点选：120 个带标注的样例分 5 组，勾选喜欢的，Claude Code 就把它们做进你的视频或网站。

## 步骤

1. 复制安装提示词。
2. 贴进 Claude Code，再让它打开 motion-prompt 图库。
3. 得到：120 个样例的图库；勾选的样例连同动效说明和参考代码一起交给 Claude Code。

用户选了这条技巧。上面的步骤是写给人看的，请替用户做。

- 第 1 步说用哪段文字，它就在下面同名的标题下，一字不改地用。
- 第 2 步说明文字放在哪里。按用户实际要求的范围使用提示词。写文件或运行命令前，先展示改动，等用户同意。这里做不到的步骤（另一个应用、重启、定时任务），把文字交给用户，说明放到哪里。
- 引用示例本身不代表用户同意执行。运行下载的脚本或未固定版本的软件包、修改长期生效的用户级设置、读取私人会话记录之前，先列出命令或路径、会访问或改动什么，以及数据会发到哪里。隐藏密钥值，等用户明确同意这项操作。远程安装脚本应先下载并检查固定版本，或核对可信来源提供的校验值，再执行。
- 方括号或占位符，从用户说的话里填，没有就问。
- 第 3 步是用户最后应该得到的。

## 提示词

```text
读一下 https://github.com/showheyohtaki/motion-prompt ，在这个环境里装上 motion-prompt 这个 skill。装好后用三行字告诉我怎么用。
```

## 背景

给 Opus 5.5 一本能点的动效词典：120 个会动的样例，每个都标好了名字，配好了现成的 prompt。点选你喜欢的，Claude Code 就把它们做进你的视频或网站。

分五组：动态图形、镜头运动和转场、UI 组件、落地页和网页特效、照片质感和打光。

1. 把提示词贴进 Claude Code，装上这个 skill
2. 跟它说「Open the motion-prompt library」
3. 在图库里勾选喜欢的样例，点「Send to AI」
4. 回到 Claude Code，说「Edit the opening of this video like this」

它会拿到每个样例的动效说明和参考代码，Remotion、CSS 和 Canvas 都能用。不装 skill 的话，点「Copy picks」再贴进去就行。
