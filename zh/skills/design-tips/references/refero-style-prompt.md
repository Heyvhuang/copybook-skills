# Refero 风格提示词：先出设计方案

页面换哪家创业公司都一样：以 Refero 风格为参考，先批方案，再写进 DESIGN.md，截图对照它检查。

## 步骤

1. 复制提示词，填进你选的 Refero 风格链接。
2. 在项目里把它发给 Claude Code 或 Codex。
3. 得到：一份要你批准的设计方案，然后是 DESIGN.md、实现，以及对照它检查过的截图。

用户选了这条技巧。上面的步骤是写给人看的，请替用户做。

- 第 1 步说用哪段文字，它就在下面同名的标题下，一字不改地用。
- 第 2 步说明文字放在哪里。按用户实际要求的范围使用提示词。写文件或运行命令前，先展示改动，等用户同意。这里做不到的步骤（另一个应用、重启、定时任务），把文字交给用户，说明放到哪里。
- 引用示例本身不代表用户同意执行。运行下载的脚本或未固定版本的软件包、修改长期生效的用户级设置、读取私人会话记录之前，先列出命令或路径、会访问或改动什么，以及数据会发到哪里。隐藏密钥值，等用户明确同意这项操作。远程安装脚本应先下载并检查固定版本，或核对可信来源提供的校验值，再执行。
- 方括号或占位符，从用户说的话里填，没有就问。
- 第 3 步是用户最后应该得到的。

## 提示词

```text
以 <REFERO_STYLE_URL> 作为这个项目的设计参考。不要照搬它的品牌、文案或整页布局。

写代码之前，先给我一份设计方案：

→ 页面的受众和唯一目标
→ 4 到 6 个颜色 token
→ 标题和正文字体
→ 布局构思和一张 ASCII 线框图
→ 一个标志性元素
→ 你从参考里保留了什么、改了什么，以及为什么

如果同一份方案原封不动地也适用于另一家创业公司，就重做。

我批准之后，把最终方案保存到 DESIGN.md，然后实现。完成后，截取桌面端和移动端的截图。对照 DESIGN.md 检查颜色、字体、间距和布局。
```

## 背景

2,000+ 套完整的设计系统，给 Claude Code 和 Codex 用，都在一个网站上：[Refero Styles](https://styles.refero.design)。打开任意一套，你会拿到：

- DESIGN.md
- Tailwind v4
- CSS 变量
- 设计 token
- 字体、颜色、间距、组件，以及该做和不该做的事

选一个和你的产品接近的 Refero 风格。Anthropic 的 frontend-design skill 在写代码前加了一条有用的规则：先选定审美方向，方案要是原封不动放到另一家创业公司也成立，就否掉。
