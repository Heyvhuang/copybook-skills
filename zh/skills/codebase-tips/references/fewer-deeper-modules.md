# 代码清理提示词：模块更少、更深

功能跑通了，代码却到处重复：重复的删光，核心逻辑归到一处。

## 步骤

1. 复制提示词。
2. 发给 Claude Code 或 Codex，每跑通一个功能就发一次。
3. 得到：行数降下来，抽象更巧妙，整个代码库前后一致。

用户选了这条技巧。上面的步骤是写给人看的，请替用户做。

- 第 1 步说用哪段文字，它就在下面同名的标题下，一字不改地用。
- 第 2 步说明文字放在哪里。按用户实际要求的范围使用提示词。写文件或运行命令前，先展示改动，等用户同意。这里做不到的步骤（另一个应用、重启、定时任务），把文字交给用户，说明放到哪里。
- 引用示例本身不代表用户同意执行。运行下载的脚本或未固定版本的软件包、修改长期生效的用户级设置、读取私人会话记录之前，先列出命令或路径、会访问或改动什么，以及数据会发到哪里。隐藏密钥值，等用户明确同意这项操作。远程安装脚本应先下载并检查固定版本，或核对可信来源提供的校验值，再执行。
- 方括号或占位符，从用户说的话里填，没有就问。
- 第 3 步是用户最后应该得到的。

## 提示词

```text
模块更少、更深，接口更小。数据只在进来的地方检查一次，之后直接用。一次性的逻辑就写在用它的地方，不要提前拆成函数。能不用 try/catch 就不用。
```

## 背景

强烈推荐试试眼下最强的代码清理 prompt。只有 5 个词：「fewer, deeper modules, smaller interfaces」（模块更少、更深，接口更小）。

最爽的是看着行数一路往下掉，所有重复代码都被清掉，核心逻辑归到一处。AI 会想出巧妙得多的抽象，顺手修掉一堆 bug，最后整个代码库前后一致。
