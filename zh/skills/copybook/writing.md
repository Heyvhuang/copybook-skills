# 写作 · 5 条

Copybook 的 5 条「写作」技巧。顺序按收藏数，不按合不合适：读完整个列表再选，合适的那条常常在后面。每条的文件是 `../writing-tips/references/<名字>.md`，在它所属话题的技能里。

| 技巧 | 做什么 |
| --- | --- |
| orwells-6-writing-rules | 一个词一个词禁 AI 腔禁不完：1946 年的 6 条规则放进全局规则文件，附重写文档和 PR 的提示词。 |
| task-brief-from-gpt-6-pro | 任务没想透就派给 Codex：GPT-6 Pro 先挑出没想清楚的地方，写成工程师能直接接手的说明。 |
| one-line-against-ai-prose | 删掉「不是 X，而是 Y」还是像 AI：Anthropic 的 Fable 5.1 指南给了一句更直接的提示词。 |
| readme-rewrite-and-polish | 用户明确要为新读者重写整份 README 时使用。只补安装步骤或改单段时，直接做局部修改。 |
| content-team-of-9-skill-sets | 一个人做内容：装好选题、写作、配图、视频、声音和排期的 skill，再拿一个选题试跑。 |
