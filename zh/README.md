# copybook-zh

The Chinese edition of Copybook has ended, and this plugin now carries the same English skills as copybook: install copybook and remove copybook-zh.

Keep one of the two: with both installed, every Copybook skill is listed twice. In Claude Code:

```bash
claude plugin install copybook@copybook --scope user
claude plugin uninstall copybook-zh@copybook --scope user
```

In Codex:

```bash
codex plugin add copybook@copybook
codex plugin remove copybook-zh@copybook
```

Until you switch, copybook-zh keeps updating with the same skills as copybook. Every tip and the other ways to install are in the [README](https://github.com/Heyvhuang/copybook-skills/blob/main/README.md).
