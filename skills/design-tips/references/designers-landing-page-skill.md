# A designer's landing-page skill

A landing page that looks designed: layout, copy, fonts and spacing handled after one round of questions.

1. Copy the prompt.
2. Paste it into Claude Code in your project, or into Codex with the one change the tip gives.
3. You get: A landing page for your project, with the layout, the copy, the fonts and the spacing handled.

## Prompt

```text
Install the landing-page-design skill from the elayadesign/ai-design-skills repo on GitHub into this project's .claude/skills, then use it to build a landing page for this project. Ask me all your questions in one go before you start.
```

## Background

A designer just open-sourced their secret weapon for landing pages. It handles the layout, the copy, the fonts and the spacing for you.

In Claude Code the prompt installs the skill and starts your first page.

On Codex, change "into this project's .claude/skills" to "by appending its SKILL.md to AGENTS.md".
